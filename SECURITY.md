# Security

Lola-Bla is a hobby project built for a small child's robot. Please be kind and specific. I take reports seriously, above all anything that could expose a child, a family's messages or a phone number.

## Report a problem privately

Use GitHub's private reporting: open the **Security** tab of this repository, then **Report a vulnerability**. Please do not open a public issue for a security problem, and never paste phone numbers, tokens, Signal data or logs into a public issue.

## In scope

- The settings console and the small page this repository serves
- How the app stores data, handles secrets and talks to Signal
- Anything in the docs that is wrong in a way that could put someone at risk

## Not in scope here

- The Reachy Mini robot software, its daemon and the Control app (Pollen Robotics): please report those to Pollen
- Signal, signal-cli-rest-api and Hugging Face
- Attacks that need access to the owner's home network: they are known and written down in [the security review](docs/reference/security-review.md)

## What to expect

I read every report and answer as soon as I can. There is no bounty.
