# Use Lola-Bla

<img src="../brand/lola-bla-mark.svg" alt="Lola-Bla" width="96" align="right">

**talk to abuelo without a phone.**

Lola-Bla turns your Reachy Mini into a friend for a small child. She can hear Signal voice messages from family far away, record an answer, and send it back, just by talking. You decide who is allowed to talk to her. She never needs a screen, a phone or a keyboard.

## What you need

- A **Reachy Mini Wireless** that is set up and on your home Wi-Fi
- A **Signal account** on your phone (Lola-Bla links to it as one more device, like Signal Desktop)
- A **Hugging Face account** (the live conversation and the small messaging assistant use it)
- A computer with a browser, to set things up once

## Good to know before you start

- Lola-Bla is a hobby project that I built for my own daughter, and I share it as it is. It is **not** a finished product, and it is not yet in the Reachy Mini app store: today you install it from this repository.
- Part of the conversation runs in the cloud. Read [Safe and private](safe-and-private.md) before you decide.
- Looking for how it is built instead? Start at the [docs home](../README.md).
