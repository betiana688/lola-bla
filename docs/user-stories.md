# User stories

## Story 1: Check messages

As Betiana, I ask Reachy to check messages, and Reachy plays new audio messages from the allow-listed Signal groups aloud.

## Story 2: Reply with audio

As Betiana, I ask Reachy to reply to a contact or group and record an audio message.

- While recording: pause and resume.
- After stopping, choose one:
  - **Replay**, then decide again
  - **Send**
  - **Delete**

## Story 3: Configure via web console

As Betiana, I configure the app in a web console, separate from the voice interface.

- Add, edit and remove allowed contacts and groups.
- Only Betiana adds contacts (no adding by voice).
- See activity logs, including failures.

## Phase 2 (later): NFC figurines

Lola taps an NFC figurine to check messages or reply to a person, without needing to speak.
